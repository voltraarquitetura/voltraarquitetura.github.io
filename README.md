# Sistema Voltra

Sistema interno da Voltra Arquitetura & Engenharia: escritório, missões, validações e esteira de projetos.

- **Endereço:** https://voltraarquitetura.github.io/
- **Login e dados:** Firebase (projeto `voltra-sistema`). Os dados não ficam neste repositório.
- **Regras de segurança do banco:** `firestore.rules`. Elas são publicadas no console do Firebase (Firestore Database › Regras); este arquivo é a cópia de referência.

Só entra quem tem login criado pela gestão (Ajustes › Acessos ao site).
